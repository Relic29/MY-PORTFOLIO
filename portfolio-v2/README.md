My personal cybersecurity portfolio showcasing my experience, projects, research, certifications, and achievements.

🌐 **Live Demo:** https://relicrhofl-portfolio.netlify.app/

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Relic29/MY-PORTFOLIO.git
```

### Navigate to the project

```bash
cd portfolio-v2
```

### Run the project

Simply open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.
